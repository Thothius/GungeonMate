How to use: run SERVE_LAB.bat (serves gungeon_mate/ on port 8619), then open a view. The toolbar switches phone width (320–768dp, matching ScreenProfile breakpoints) and text scale (1.0/1.3× accessibility check). CSS vars in tokens.css are named after Dart tokens — a tweak ports back 1:1 (--inset-md → Insets.md). Rules of the system live in ../DESIGN.md. This lab is a design sandbox — verify final values in the real app.
